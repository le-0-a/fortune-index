# 오늘의 운세 지수

오늘 하루의 종합 운세 지수와 금전운, 커리어운, 연애운, 행운운을 재미로 확인하는 반응형 웹앱입니다. 순수 HTML, CSS, JavaScript로 만들었으며 별도의 설치나 외부 라이브러리가 필요하지 않습니다.

## 실행 방법

1. `index.html`, `style.css`, `script.js`를 같은 폴더에 둡니다.
2. `index.html`을 브라우저에서 엽니다.
3. **오늘의 운세 뽑기** 버튼을 눌러 결과를 확인합니다. 버튼을 다시 누르면 새 결과를 뽑을 수 있습니다.

로컬 서버를 사용하고 싶다면 프로젝트 폴더에서 `python -m http.server 8000`을 실행한 다음 브라우저에서 `http://localhost:8000`을 여세요.

## 구성

- `index.html`: 앱의 콘텐츠와 접근성 있는 화면 구조
- `style.css`: 반응형 레이아웃, 색상, 점수 표시와 애니메이션
- `script.js`: 한국 날짜 표시, 운세 점수와 코멘트 생성

결과는 매번 무작위로 생성되며, 재미를 위한 콘텐츠입니다. Google Fonts 연결이 차단된 환경에서는 시스템 글꼴로 표시됩니다.
